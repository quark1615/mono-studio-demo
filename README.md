# MONO STUDIO v0.5 — 무료 뉴스 수집 + 모바일 카드뉴스

이 저장소는 아이폰 Safari에서 사용하는 개인용 PWA 테스트 프로그램입니다.

## 바로 접속

https://quark1615.github.io/mono-studio-demo/

## 매일 8시(KST) 뉴스 수집

- GitHub Actions: `.github/workflows/daily-news.yml`
- UTC 23:00 = 다음 날 한국시간 08:00. GitHub 예약 실행은 지연/누락될 수 있어 정시 제공을 보장하지 않습니다.
- 자동 실행 또는 Actions 메뉴에서 수동 실행 시 `scripts/fetch_news.py`가 Google News의 **RSS 제목·출처·링크·발행시각**을 수집합니다.
- 지난 24시간 쇼핑/패션/뷰티 **최대 20건**, 추가로 생활템 최대 8건, 음식 최대 8건, 연예/컬처 최대 12건을 시도합니다. 건수가 부족하면 임의 데이터를 만들지 않습니다.
- 결과: `data/latest_news.json`. 수집 성공 후 GitHub Actions가 파일과 `assets/editorial/` 추상 SVG 그래픽을 자동 커밋합니다.
- 아이폰에서 웹앱을 열고 **뉴스함 → 새로고침**을 선택합니다. 현재 푸시 알림은 없습니다.

## 이미지 사용 범위

- 기사별 SVG 표지 이미지는 스튜디오 코드가 직접 생성한 **추상적인 자체 그래픽**입니다. 실제 기사 사진·영화 포스터·연예인 사진·실제 상품 사진이 아닙니다.
- 실제 사진을 사용하려면 별도로 상업적 사용 허락·초상권·브랜드 정책을 확인한 뒤 앱 편집기에서 수동 업로드해야 합니다.
- 유료 생성형 AI 이미지, 뉴스 본문 AI 분석, 실제 쿠팡 상품 자동 조회는 현재 연결되지 않았습니다.

## 제작 방법

1. 아이폰 Safari에서 위 주소 열기
2. 뉴스함에서 **실제 RSS 기사 후보**를 선택하고 원문 확인
3. 최대 5장 초안 생성 (마지막 장은 채널 홍보)
4. 요약·후킹 제목·핵심 사실을 직접 검수/수정
5. 이미지 수정(권리 확인 체크), Instagram 4:5 또는 TikTok/Shorts 9:16 선택
6. JPG/ZIP 저장 후 SNS 직접 발행

## 데이터 백업과 안전

- 기존 `localStorage` 키 `mono_v1`을 그대로 사용합니다. 앱 코드가 업데이트되어도 동일한 브라우저/주소에 기존 설정·초안을 유지하도록 설계했습니다.
- GitHub 공개 저장소에는 개인 JSON 백업·SNS 인증정보·API 키를 올리지 마세요.
- 설정의 **JSON 백업**은 텍스트/설정 중심이며 **직접 업로드한 이미지 파일은 포함되지 않습니다**. 원본 사진과 로고는 별도 보관하세요.
- 앱의 페이지는 공개 접근이 가능합니다. SNS 로그인이나 클라우드 동기화는 제공되지 않습니다.
