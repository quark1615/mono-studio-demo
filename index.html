채널별 출력

발행은 직접 진행합니다. 크기와 문구를 바꾼 뒤 저장하세요.

출력 채널 선택

카드 이미지는 고해상도 캔버스에서 직접 생성됩니다. 실제 SNS 자동 발행은 아직 연결되지 않았습니다.

채널용 캡션

어필리에이트 링크를 활용할 경우 게시물과 링크 안내 영역에 적절한 경제적 이해관계 표시를 하세요. 링크 삽입 가능 위치는 플랫폼별로 다릅니다.

계정 · 테마 설정

테마별 채널명, 목소리, 로고를 별도로 저장합니다.

언어 선택은 새 카드의 기본 문구와 캡션에 적용됩니다. 사용자가 입력한 기사·경전은 자동 번역하지 않습니다.

저작권이 있는 번역본의 전문 자동 복사는 제공하지 않습니다.

새로운 주제 추가

새 테마가 생성되면 뉴스함·편집기·출력 도구를 그대로 공유합니다. 뉴스 수집 규칙과 전문 팩트체크는 이후 개별 설정합니다.
